What Step 2 remembers

Step 2 does not reset when you close the app. Everything on the page is restored the next time you open it — which is convenient, and the reason a setting changed once keeps applying.

When settings are saved

Your Step 2 settings are written when you leave the step or move on in the wizard, not on every keystroke. That includes the system prompt, so a prompt you have typed and used is never only in memory.

At startup the form is pre-filled from the saved values, so a repeated run is the same run.

What is remembered

SettingRestored as
Model idThe model the next run uses. Also kept in the app config file.
DeviceCPU, CUDA or MPS.
Confidence, probability mode, probability threshold, candidate labelsYour last values. These do not affect the local model; see Step 2 — Tagging Engine.
System promptThe prompt in the box, exactly as typed.
Tag instructionYour custom instruction, if you wrote one. Blank means the built-in instruction and is stored as blank.
Tag fieldsWhich of the three fields get written — the setting most likely to surprise you later.

Separately, the saved system prompts are kept as a list in their own file, so you can prune that history without touching the settings of a run. See Prompts.

Where it is stored

On Windows, in the registry under HKCU\Software\Synapic\Engine, as one value per setting. Nothing here needs administrator rights: it is a per-user key.

Off Windows, nothing is remembered.

That store is Windows-only by design. On Linux and macOS the app works normally, but Step 2 starts from its defaults each time — worth knowing before you build a workflow that depends on a saved custom prompt.

Resetting Step 2 to its defaults

To undoDo this
A changed settingChange it back in Step 2 and leave the step. That is all: the values are read from the form.
A partial tag-field selectionTick all three Tag fields boxes, and check the orange warning line has gone.
A custom tag instructionReset to built-in, which clears the box.
Everything at onceDelete the Engine key (or edit individual values) with Registry Editor. The app recreates it on the next save with default values.

Editing the registry is immediate.

The app reads these values at startup and writes them on leaving Step 2, so changing the key while Synapic is running can be overwritten by the running app. Close it first. Files, folders and registry keys lists every value by name.

Settings that are not in Step 2

  • The Daminion connection, scope, filters and limits belong to Step 1. See Connecting to Daminion.
  • Whether the inference server starts with the app is a config-file setting, not a UI option: ui.autoLaunchSidecar in %APPDATA%\Synapic\config.json. See Files, folders and registry keys.
  • The model cache is shared by every install on the machine and lives outside both stores. See Build the inference server.
