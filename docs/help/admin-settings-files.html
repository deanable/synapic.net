Files, folders and registry keys

Everything Synapic writes, and where. Useful for scripting a rollout, backing up a user's configuration, or proving to an auditor that nothing interesting leaves the machine.

Files and folders

WhatPathNotes
Application settings%APPDATA%\Synapic\config.jsonWizard defaults and UI preferences. Off Windows: $XDG_CONFIG_HOME/Synapic/config.json or ~/.config/Synapic/config.json.
Saved system prompts%APPDATA%\Synapic\system-prompts.jsonThe Step 2 prompt history, newest first. Pruning it never changes a run's current settings. See Prompts.
Current loglogs\synapic.log next to the executableFalls back to %LOCALAPPDATA%\Synapic\logs when the install folder is not writable. Starts empty each run.
Previous logslogs\archives\Each start moves the previous log in here; the ten most recent are kept.
Crash reportslogs\crashes\One text file per crash: the exception plus a snapshot of the run's log.
Usage counterslogs\synapic-usage.jsonOnly written when the user opts in. Local counts, no service involved.
Model cache%LOCALAPPDATA%\Synapic\modelsPer user, shared by every Synapic install for that user. Off Windows: ~/.cache/synapic/models. Deleted by the uninstaller.
Inference server port file%TEMP%\synapic_port_<pid>.txtTwo lines: the port, then the server's process id. Created per launch and used to find the server; it contains nothing sensitive.

The configuration file

JSON with a version number (currently 2). Unknown fields are preserved when the app rewrites it, so a hand-added key survives.

KeyMeaning
versionConfig schema version.
datasource.type, .localPath, .localRecursiveThe local-folder side of Step 1.
datasource.daminion.*Server URL, username, scope, search term, ids, untagged filters, status filter and max items. The password is not here; it lives encrypted in the registry.
engine.modelId, .task, .deviceThe default engine selection, for example LiquidAI/LFM2.5-VL-450M, image-text-to-text, cpu.
engine.confidenceThreshold, .probabilityMode, .probabilityThreshold, .probabilityCandidatesThe scoring controls. They do not affect the local vision-language model.
engine.systemPrompt, .userPromptThe two prompt boxes. An empty userPrompt means the built-in tag instruction.
processing.maxItems, .autoPaginate, .resizeScale, .useThumbnailOverrideBatch size and image-scaling defaults.
ui.theme, .logLevelsystem theme and info logging by default.
ui.autoLaunchSidecartrue by default: the inference server starts with the app. Set it to false to make starting the server a manual step.
ui.telemetryEnabledfalse unless a user opts in.

Registry keys

Both stores are under HKEY_CURRENT_USER, so they are per user and need no administrator rights. They exist on Windows only: on Linux and macOS the app runs with defaults and forgets these settings between runs.

Step 2 — HKCU\Software\Synapic\Engine

ValueTypeDefault
ModelIdStringLiquidAI/LFM2.5-VL-450M
TaskStringimage-text-to-text
DeviceStringcpu (others: cuda, mps)
ConfidenceThresholdString (number)0.3
ProbabilityModeStringboth (others: llm, probability)
ProbabilityThresholdString (number)0.5
ProbabilityCandidatesStringempty
SystemPromptStringempty
UserPromptStringempty, meaning the built-in tag instruction
EmbeddingRescueEnabledDWORD0. Persisted for compatibility; the local model does not use it.
TagKeywordsDWORD1. Whether keywords are written.
TagCategoriesDWORD1. Whether the category is written.
TagDescriptionDWORD1. Whether the description is written.

Those last three values are the ones to check first in the field.

They are the persisted tag-field selection, and if one is 0 the app will quietly stop writing that field to every item. Reading them takes seconds and settles the most common "Synapic only wrote keywords" report.

Step 1 — HKCU\Software\Synapic\Daminion

ValueMeaning
ServerUrl, UsernameThe last connection that worked.
PasswordEncryptedThe password, protected with Windows DPAPI for that user on that machine. Copying it elsewhere does not work, by design.
DaminionScopeall, search, collection or saved_search.
SearchTerm, SavedSearchId, CollectionIdThe scope's parameters.
StatusFilterall, approved, rejected or unassigned.
UntaggedKeywords, UntaggedCategories, UntaggedDescriptionThe "only items with untagged" filters.
MaxItemsThe batch ceiling used in the last connect, 100 by default.
ResizeScale, UseThumbnailOverride, ProcessAllImage scaling and the page-until-empty switch.

This key is written only after a successful login, so a mistyped password can never overwrite a working configuration. Deleting the key resets Step 1 to defaults.

Backing up a user's configuration

  1. Export both registry keys above with Registry Editor, or copy the values with a script.
  2. Copy %APPDATA%\Synapic\config.json and, if the user cares about the prompt history, %APPDATA%\Synapic\system-prompts.json.
  3. The model cache is a download, not configuration: copy it only to save time on an offline machine.

Do not edit these while Synapic is running.

The app reads settings at startup and writes them when you leave a step, so a change made in the middle of a session can be overwritten. Close the app first. See What Step 2 remembers.
