Deduplication

A separate tool, not part of the tagging wizard: it scans a source for images that look the same, groups the candidates into a vertical list, and lets you decide which copies to keep before acting on the rest. The source is either a local folder or the Daminion catalog — the same choice Step 1 makes for tagging.

Choosing the source

  1. Pick Local Folder or Daminion Catalog at the top. The catalog side reuses the scope configured in Step 1 (entire catalog, keyword search, shared collection or saved search) — its summary is shown above the scan button.
  2. For a local source, give it a Folder to scan (with Browse… if you prefer). Subfolders are included automatically and the scan covers .jpg, .jpeg, .png, .tif and .tiff. For the catalog source, each original is downloaded to a temporary file, hashed and deleted again — one at a time, so a big collection never lands on disk whole.

Scanning

  1. Choose an algorithm and a Threshold. The defaults are a good starting point.
  2. Press Scan. Progress is reported as files are hashed: Hashed 240/1500… — or as items are downloaded for the catalog source.
  3. Read the summary: 1500 files scanned — 12 groups, 18 duplicates.

Algorithms and the threshold

Every algorithm reduces an image to a 64-bit perceptual fingerprint. Two images are "the same" when their fingerprints differ by no more than the threshold allows.

AlgorithmGood at
PHashThe general-purpose default. Tolerates re-encoding, resizing and mild retouching, and is the least likely to confuse two unrelated photos.
DHashSmall images and subtle brightness differences; often picks up duplicates PHash misses in low-contrast sets.
AHashThe simplest and fastest. Adequate for exact copies and resizes, and the most sensitive to brightness changes.
ColorMomentColour and tone, ignoring structure. Useful for finding graded versions of the same shot, and the one most likely to group images that merely share a palette.
ThresholdEffect
0.90 (default)Close matches only. Start here: it finds copies and re-encodes with few false groups.
0.95 or higherNear-identical. Good when you are hunting exact duplicates and want no noise at all.
0.80 or lowerLoose: catches cropped or heavily edited versions, and starts grouping visually similar but different images. Expect to review the groups carefully.

Scan a copy first if the stakes are high.

Scan the folder, look at the groups, and only then decide on an action. The scan itself changes nothing: it reads files and hashes them.

Reviewing the groups

Groups appear as cards in a vertical list. Each card shows how many images it holds and lists them as rows — name, capture date and file size — every row with its own checkbox. A checked item is kept; the action applies to the unchecked ones.

Instead of ticking rows by hand, use the Auto-select keep-set switches above the list: Oldest, Newest, Smallest and Largest. Each active switch ticks the item it names in every group; several switches tick the union of their picks. Ties go to the earlier item in the group, items with no date or size are never picked, and toggling a switch recomputes the whole selection — hand tweaks after that stick until you toggle a switch again. With no switch active, the first item of each group is kept.

Read the group list before applying anything.

The default keep-set is the first file the scan found, not the best one — use the auto-select switches or tick rows yourself when the order is wrong. A group of two is easy to read; a group of nine is worth opening a couple of.

ActionWhat it actually does
Delete (local source)Deletes the unchecked files permanently. This is a real delete, not a move to the Recycle Bin, and there is no undo.
Move (local source)Moves the unchecked files into a duplicates subfolder beside each file. Nothing is destroyed, and the files stay in the same tree. If a file of the same name is already in that subfolder, that move fails and is reported in the log — the original is left where it is.
Tag (local source)Not implemented in this version. It records the intent in the log and changes nothing, so do not rely on it to mark duplicates. Use Move, or note them in your catalog by hand.
Delete from catalog (Daminion source)Removes the unchecked items from the Daminion catalog. The original files on the server are not touched, but the catalog entries are: a confirmation prompt appears first, and after that there is no undo. The scan itself changes nothing — only Apply does.

After an action the groups it touched are removed from the list and the summary reports the result, for example Move applied to 4 duplicate(s). Anything that failed is in the log.

What this tool is not

  • It does not find similar images by content or subject — only perceptually equal ones.
  • It does not remember a scan between sessions, and it does not watch a folder. Each scan is a fresh pass.
