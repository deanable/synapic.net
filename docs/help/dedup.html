Deduplication

A separate tool, not part of the tagging wizard: it scans a folder for images that look the same and lets you act on the groups it finds. It works on files, not on Daminion items.

Scanning

  1. Give it a Folder to scan (with Browse… if you prefer). Subfolders are included automatically and the scan covers .jpg, .jpeg, .png, .tif and .tiff.
  2. Choose an algorithm and a Threshold. The defaults are a good starting point.
  3. Press Scan. Progress is reported as files are hashed: Hashed 240/1500…
  4. Read the summary: 1500 files scanned — 12 groups, 18 duplicates.

Algorithms and the threshold

Every algorithm reduces an image to a 64-bit perceptual fingerprint. Two images are "the same" when their fingerprints differ by no more than the threshold allows.

AlgorithmGood at
PHashThe general-purpose default. Tolerates re-encoding, resizing and mild retouching, and is the least likely to confuse two unrelated photos.
DHashSmall images and subtle brightness differences; often picks up duplicates PHash misses in low-contrast sets.
AHashThe simplest and fastest. Adequate for exact copies and resizes, and the most sensitive to brightness changes.
ColorMomentColour and tone, ignoring structure. Useful for finding graded versions of the same shot, and the one most likely to group images that merely share a palette.
ThresholdEffect
0.90 (default)Close matches only. Start here: it finds copies and re-encodes with few false groups.
0.95 or higherNear-identical. Good when you are hunting exact duplicates and want no noise at all.
0.80 or lowerLoose: catches cropped or heavily edited versions, and starts grouping visually similar but different images. Expect to review the groups carefully.

Scan a copy first if the stakes are high.

Scan the folder, look at the groups, and only then decide on an action. The scan itself changes nothing: it reads files and hashes them.

Acting on a group

Groups appear on the left, each listing the files it believes are the same. Select one, choose an action, press Apply.

One file per group is kept, and it is the first one found.

The action applies to every other file in the group. The kept file is chosen by the scan's own ordering, not by size, date or quality, so check the group list before applying anything. A group of two is easy to read; a group of nine is worth opening a couple of.

ActionWhat it actually does
DeleteDeletes the duplicate files permanently. This is a real delete, not a move to the Recycle Bin, and there is no undo.
MoveMoves the duplicates into a duplicates subfolder beside each file. Nothing is destroyed, and the files stay in the same tree. If a file of the same name is already in that subfolder, that move fails and is reported in the log — the original is left where it is.
TagNot implemented in this version. It records the intent in the log and changes nothing, so do not rely on it to mark duplicates. Use Move, or note them in your catalog by hand.

After an action the group is removed from the list and the summary reports the result, for example Move applied to group (4 duplicates). Anything that failed is in the log.

What this tool is not

  • It does not compare images in Daminion. Scan an exported folder instead.
  • It does not find similar images by content or subject — only perceptually equal ones.
  • It does not remember a scan between sessions, and it does not watch a folder. Each scan is a fresh pass.
