What you need

Synapic runs the model locally, so most of what it needs is disk space and patience on the first run. It does not need an internet connection to tag, once the model is on the machine.

Operating system

PlatformWhat you get
Windows 10 or 11, 64-bitThe installer (Synapic-Setup-win-x64.exe) — the primary, fully supported platform. Everything in this help is written for it.
macOS on Apple siliconA disk image (Synapic-osx-arm64.dmg) built by the same pipeline.
Linux, 64-bitNo installer yet. Take the published Linux inference server and run it beside a build of the app.

Step 1 and Step 2 settings are stored in the Windows registry.

On Windows, the app remembers your Daminion connection and your engine settings between runs. Off Windows there is no registry, so those stores do nothing: the app still works, but you re-enter the settings each time. See Files, folders and registry keys.

Software

  • .NET 10 Desktop Runtime. Required, and the Windows installer handles it: it either bundles a copy or downloads the official installer at the Ready step and runs it silently. You only meet this if you install by copying files.
  • Daminion Server (only if you tag a catalog rather than a folder): the HTTP API reachable from the machine, plus an account that may read the items and update their metadata.
  • Git, .NET SDK and Python are needed only to build Synapic or its inference server from source, not to use a release.

Disk space

WhatSpaceWhere it goes
The applicationA few hundred MBC:\Program Files\Synapic
The modelAbout 860 MB, once%LOCALAPPDATA%\Synapic\models (shared by every install of the app)
Building the CPU inference serverSeveral GB, during the build onlyA build workspace under the app's own folder; the result is one executable
The CUDA inference serverAbout 2.5 GB as a finished executableSame as above

Uninstalling removes the model cache.

The Windows uninstaller deletes %LOCALAPPDATA%\Synapic\models, so a reinstall downloads the model again. If you plan to reinstall, or you are on a metered connection, copy that folder somewhere safe first.

Hardware

  • Any modern 64-bit CPU runs the model. Expect roughly ten seconds per image on a mid-range laptop CPU, which is why tagging a large catalog is a background job rather than something you watch.
  • An NVIDIA GPU with a current driver makes it substantially faster. Synapic ships a CUDA build of the inference server for that case; see Build the inference server.
  • 16 GB of RAM is comfortable. The model itself needs a little over a gigabyte, and the app runs up to four images at once.
  • An SSD matters more than you would expect for a large Daminion batch, because every image is fetched (or read) before tagging.

Network

Nothing about tagging leaves the machine: the app talks only to the inference server on 127.0.0.1 and to your Daminion server. An internet connection is used for exactly three optional things: downloading the model the first time, building an inference server from source, and installing the .NET runtime when the installer cannot find one.
