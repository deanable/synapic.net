Glossary

The words this help uses, and the words your DAM uses, defined the way Synapic means them.

Synapic's own vocabulary

TermMeaning
Inference server / sidecarThe separate program that loads the model and answers one tagging request per image. Synapic starts it, talks to it over a local port, and stops it. See Build the inference server.
VariantA build of the inference server for a particular runtime: the CPU build, or the CUDA build for NVIDIA GPUs.
ModelThe vision-language network that turns an image into a category, keywords and a description. Default: LiquidAI/LFM2.5-VL-450M.
Model cacheThe folder holding downloaded model weights, shared by every install on the machine: %LOCALAPPDATA%\Synapic\models.
BatchOne run of Step 3: fetch, tag, write, for the items your Step 1 settings selected.
Tag fieldsThe three checkboxes in Step 2 that decide which of the model's results are written: keywords, categories, description.
System promptOptional context prepended to every request — tone, language, vocabulary. It must not change the output format.
Tag instructionThe instruction that asks the model for its result. Blank means the built-in instruction, which is the tested one.
ETAEstimated time remaining for a batch, calculated from completed images and their average duration. Not available until the first image finishes.
Throughput vs latencyLatency is how long one image takes (about ten seconds on CPU); throughput is how many finish per minute. Four images run at once, so those numbers differ by roughly four.
Stale buildA developer-checkout warning: the inference server executable is older than the source it was built from.
Warm-upThe server loading the model at startup so the first image of a batch does not pay for it.

Daminion and DAM vocabulary

TermMeaning in Synapic
DAMDigital asset management: the system that stores your images and their metadata. Daminion is the one Synapic integrates with.
CatalogA Daminion database. Chosen by the server URL you log in to; Synapic reports which one is active.
ScopeWhich part of the catalog a run looks at: everything, a keyword search, a shared collection, or a saved search.
Collection (shared collection)A named group of items in Daminion that people assemble by hand or by rule.
Saved searchA query saved in Daminion. The richest way to define a batch without re-creating the selection in Synapic.
Status flagDaminion's triage state for an item: approved, rejected, or unassigned. Step 1 can filter on it.
Untagged filterThe Step 1 option to select only items where keywords, categories or the description are still empty.
Item / assetOne image in the catalog. Synapic tags items; for a folder it tags files, which are the same thing.
PagingFetching items in pages. Process all keeps paging until Daminion returns nothing.

Metadata vocabulary

TermMeaning
XMPThe metadata standard Synapic writes into files. Readable by Adobe applications, Daminion and Windows itself, which is why a tagged folder travels well.
dc:subjectThe XMP property that holds keywords.
dc:descriptionThe XMP property that holds the description.
photoshop:HeadlineWhere the category goes, as a short headline.
Iptc4xmpCore:IntellectualGenreA second home for the category, understood by IPTC-aware tools.
Sidecar (the other meaning)A metadata file stored next to an image. TIFF files get an .xmp sidecar; do not confuse it with the inference server, which this help also calls a sidecar.

Deduplication

TermMeaning
Perceptual hashA 64-bit fingerprint of what an image looks like, so two copies compare as equal even after re-encoding or resizing.
pHash / dHash / aHash / ColorMomentThe four fingerprinting algorithms the deduplication tool offers, from the most robust (pHash) to the most colour-oriented (ColorMoment).
ThresholdHow different two fingerprints may be and still count as duplicates. 0.90 by default; higher is stricter.
Keep itemThe one file in a duplicate group that is left alone; the chosen action applies to the others.

Windows plumbing

TermMeaning
HKCUHKEY_CURRENT_USER, the per-user part of the Windows registry. Synapic writes there, which is why no administrator rights are needed for settings.
DPAPIWindows data protection, used to encrypt the stored Daminion password so only that Windows account on that machine can read it.
CHMCompiled HTML Help: this help file, Synapic.chm.
.NET Desktop RuntimeThe Microsoft runtime Synapic needs to start. The Windows installer supplies it if it is missing.
