Installing and upgrading

The Windows installer is a standard Inno Setup package: one executable, machine-wide install, administrator rights, and a prerequisite check for the .NET runtime.

What the installer does

ItemValue
PackageSynapic-Setup-win-x64.exe
PrivilegesAdministrator. The install is machine-wide.
Install locationC:\Program Files\Synapic (overridable on the directory page or with /DIR=)
Application idA fixed identifier, {{8A7C2C31-5E0D-4B21-9C4F-SYNAPICNET01}. It names the Add/Remove Programs entry and is what makes an upgrade replace an existing install instead of adding a second one. Do not change it in a repackaged build.
ShortcutsA Start Menu group, plus an optional desktop icon (a task, unticked by default).
Prerequisite.NET 10 Desktop Runtime. Installed silently if missing, either from a copy bundled in the setup or by downloading the official installer at the Ready step.
App layoutA framework-dependent publish: Synapic.exe and its DLLs, the inference server as synapic-inference.exe in the same folder, and the JSON files the runtime needs.

The inference server is a payload, not an optional component.

It is copied into the install folder with the app, which is why a fresh install can tag immediately and why replacing that one file swaps the model runtime. See Deploying to many machines.

Silent and scripted installation

The package accepts the standard Inno Setup switches:

SwitchEffect
/VERYSILENTNo wizard, no progress window.
/SUPPRESSMSGBOXESSuppresses prompts. Use it with /VERYSILENT so a restart prompt cannot block a script.
/NORESTARTNever restarts the machine.
/DIR="D:\Apps\Synapic"Installs somewhere other than the default folder.
/TASKS="desktopicon"Creates the desktop icon as part of the install.
/LOG="C:\temp\synapic-install.log"Writes the installer's own log, which is what you want when a deployment fails silently.

For example:

Synapic-Setup-win-x64.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /TASKS="desktopicon" /LOG="C:\temp\synapic-install.log"

The runtime prerequisite still runs in a silent install.

If .NET 10 is missing, the installer needs either the runtime payload bundled next to the setup (the release packages stage it) or an internet connection to download it. On an isolated network, use a build that bundles the runtime — otherwise the install can end with the prerequisite unresolved. The installer's log records exactly what happened.

Upgrading and uninstalling

ActionWhat survives
Install a newer version over an existing oneNothing is reset. Per-user settings (registry) and the model cache are outside the install folder and stay exactly as they were.
Replace one file to change the inference serverThe supported lightweight update: drop a new synapic-inference.exe into the install folder and restart the app. Useful for moving a machine to the CUDA build.
UninstallRemoves the application and — importantly — deletes the per-user model cache at %LOCALAPPDATA%\Synapic\models, so a reinstall downloads about 860 MB again. Settings in the registry are left alone.

Before a reinstall, copy the model cache.

%LOCALAPPDATA%\Synapic\models is pure download, so copying it out and back in saves the whole download. This is also how you seed a machine that has no internet access; see Deploying to many machines.
