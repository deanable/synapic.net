Frequently asked questions

Does Synapic upload my images anywhere?

No. The model runs on your machine, the app talks to it over a local port, and the only network traffic is to your own Daminion server. There is no cloud engine and no API key to configure, by design.

Which model does it use?

A small vision-language model, LiquidAI/LFM2.5-VL-450M by default, chosen because it is quick enough on an ordinary CPU. You can point Step 2 at another compatible model id, and the list shows what is already in the local cache. See Step 2 — Tagging Engine.

Why does the app insist on building an "inference server"?

The model needs a Python deep-learning runtime that has no business inside a desktop UI. Keeping it in its own process means the app starts instantly and a model crash cannot take your batch with it. You build it once. See Build the inference server.

Why did only keywords get tagged?

Because only keywords were selected. The three boxes under Tag fields in Step 2 decide which of the model's three results are written, and the choice is remembered. It is the first thing to check when a field is missing — ahead of the model, the prompt and the server. See the diagnosis recipe.

Does it overwrite keywords that are already there?

Yes. A run replaces the keywords, category/headline and description that Synapic manages, rather than adding to them. Nothing else in the file is touched. Keep a backup before a first large run; there is no undo.

Can I undo a run?

Not from Synapic. The writes go straight into the files or the catalog. If you need a rollback, restore from a backup or from the DAM's own version history, or re-run the items with different settings.

Which file types can it tag?

JPEG, PNG and TIFF — .jpg, .jpeg, .png, .tif and .tiff. Camera RAW files are not supported: they are skipped, so a folder of RAW files produces no work. Export JPEGs from your raw processor instead.

Does it need an internet connection?

Only to download the model the first time (about 860 MB) and to build an inference server from source (which fetches Python and packages). After that, tagging a folder works entirely offline. A Daminion run needs your own server, which is usually on the local network.

How long does a batch take?

Roughly ten seconds per image on a CPU, as a rule of thumb, with four images in flight at once. A thousand images is therefore an hour or two of unattended work; a hundred thousand is a multi-day job that belongs on a GPU machine. See speed and timings.

Is the GPU build worth it?

On a suitable NVIDIA card with current drivers, yes — often several times faster. It is not a linear speed-up though: four parallel requests share one model, so expect less than the raw hardware ratio. Judge it on a real batch.

Can two people run Synapic at the same time?

On the same machine, each app instance starts its own inference server, so they do not interfere. They do share the model cache, which is fine, and each Windows account keeps its own settings. Pointed at the same folder, though, two runs can fight over the same files — give each run a different scope.

Where are my settings kept?

Step 1's connection and Step 2's engine settings live in the Windows registry under HKCU\Software\Synapic, per user. The saved system prompts are a JSON file in %APPDATA%\Synapic, and the model cache lives in %LOCALAPPDATA%\Synapic\models. Full list: Files, folders and registry keys.

Do the confidence and probability settings do anything?

Not with the local vision-language model. They belong to the classification and zero-shot scoring paths, and are ignored here; a log line about progress scoring being unavailable is expected. Leave them at their defaults.

Can I see the tags before they are written?

Not in the wizard — the batch writes as it goes. The practical alternative is to run against a copy of the images (or a scratch collection), review the results in Step 4, and then run the real target with the settings you settled on.

What does F1 open?

This help, at the topic for what you are looking at: the setup panel while no inference server exists, otherwise the step on screen. The toolbar's Help button opens the contents instead. On Windows Synapic uses the compiled Synapic.chm beside Synapic.exe when that file is there, and the same topics in your browser when it is not; other platforms always use the browser. If the compiled pages look blank, Windows has blocked the file: right-click the .chm, choose Properties, tick Unblock. See Logs, crashes and support.
