Install and first run

From download to tagged images, in five steps. The only part that takes real time is the first one, and you only do it once.

Install

  1. Run Synapic-Setup-win-x64.exe. Windows asks for administrator rights, because the app installs under C:\Program Files\Synapic.
  2. If the .NET 10 Desktop Runtime is missing, the installer takes care of it at the Ready step — silently, from the copy bundled in the setup or by downloading the official installer. You may see a restart prompt afterwards.
  3. Choose whether you want a desktop icon, then finish. The installer offers to launch Synapic for you.

For unattended installs and for the other platforms, see Installing and upgrading.

First run

Synapic opens on the toolbar, the wizard, and the log. If this is a fresh install, the first thing you will notice is that the wizard is greyed out and a panel says Inference sidecar required. That is expected: nothing can be tagged until an inference server exists.

  1. Build an inference server. In the panel, press Build sidecar on the CPU row. The first build downloads a private Python and the packages the model needs, so expect minutes, not seconds. Full detail: Build the inference server.
  2. Let the server start. Synapic launches the server as soon as one exists, and the status dot turns green with Server running (port …). The very first launch is slow — up to a couple of minutes — because the model is unpacked and loaded.
  3. Choose images. In Step 1 — Datasource, either point at a folder on disk or connect to Daminion. For a first test, a small folder is the kindest choice.
  4. Run the batch. Go to Step 3 — Process and press Start Processing. The first image also triggers the model download (about 860 MB) if the model has never been used on this machine.
  5. Review. Step 4 — Results lists what happened to every image, and Verify Daminion Writes re-reads a Daminion catalog to confirm the tags really landed.

A safe first batch

To see what the model produces without committing anything, tag a copy of a dozen images in a folder:

  1. Step 1: choose Local Folder, point at the copy, and leave Include subfolders off.
  2. Step 2: leave the defaults. The three Tag fields boxes are ticked, so all three results are written into the files' XMP metadata.
  3. Step 3: Start Processing, then read the log as it scrolls. A line per image reports the category, the number of keywords, and the start of the description.
  4. Step 4: check the rows, then look at one of the files in your own image viewer or in Daminion to see the metadata.

What the first run costs you in time

StageWhat happensRoughly
Building the inference serverDownloads a standalone Python and the inference packages, then packages them into one executableMinutes to tens of minutes, once
First server startUnpacks the executable and imports the runtimeUp to two minutes, every launch
Model downloadAbout 860 MB, once per machineDepends on the connection
Model loadWeights into memory before the first tagTens of seconds on CPU
Each image after thatOne model call plus a metadata writeAround ten seconds on CPU; less on a GPU
