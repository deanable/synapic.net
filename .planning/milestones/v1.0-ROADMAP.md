## What shipped (as the user sees it, verified on the installed build 2026-10-24)

A dashboard-first app: cold start lands on the Settings view with the operation routes in the sidebar
(Settings, Tagging, Deduplication, Similar images, Upscaling); each route is one window with the
source summary, its run bar and its report; every parameter is editable in place on the Settings
view's tabs — no operation-settings dialog exists. Every long-running action shows busy state with a
working Stop; every empty-result and report branch the UI can reach is inventoried in
`docs/ui-empty-branches.md` with the behavioral test that names it, kept honest by a drift check that
fails the suite when a citation rots.

## The long tail between execution and ship

Phase 3 executed in two days; the gate then stood open for two weeks on one criterion's wording —
"every empty result has guidance copy" quantified over a set nobody had written down. The fix was not
to weaken the claim but to make it finite and checkable (GATE-01's restatement). Writing the missing
tests found two real defects users had been reading every run ("LLM only" mislabeling the scoring
mode; "No results yet" appended to populated reports). That discipline — no ✅ without recorded
evidence — is what v1.2 was for, and it is what this archive certifies.
