- [x] **Criterion 1 — cold start on the dashboard:** exactly four operation panels (Settings, Tag, Dedup, Upscale), each opening its own view. *Evidence: `RouteSplitTests`/`WorkflowOrderTests` facts; re-observed 2026-10-24 on the installed build (the sidebar has since gained a fifth route, Similar images — a superset, recorded in `03-UAT.md`).*
- [x] **Criterion 2 — one layout, three modes:** the same DataSource → Parameters → Output order on every operation route. *Evidence: `WorkflowOrderTests` + `UiLayoutAuditTests` (12 route-size combinations).*
- [x] **Criterion 3 — shared source:** the same source view-model and count on every route. *Evidence: `RouteSplitTests` + `OperationShellViewModel` wiring.*
- [x] **Criterion 4 — no operation-settings dialogs; every parameter reachable inline.** *Evidence: compiled-assembly type checks + source greps + per-mode parameter facts. In the shipped UI the per-mode parameters live on the Settings view's tabs (one concern per tab); no dialog exists anywhere in the flow — re-observed 2026-10-24.*
- [x] **Criterion 5 — layout audit green** at 900×600 … 1600×900 for dashboard + all three operation routes, including the stacked (narrow) variant. *Evidence: `UiLayoutAuditTests` 20/20 (the count of record; see `03-05-SUMMARY.md`).*
- [x] **Criterion 6 — busy + Stop for every long-running action, and every empty-result/report branch inventoried with the test that names it.** *Restated 2026-10-23 (v1.2 GATE-01) from the original uncheckable wording ("every empty result has guidance copy"); the inventory is `docs/ui-empty-branches.md` (56 rows: 55 named, 1 shadowed), drift-checked by `EmptyBranchInventoryTests` over every `Named by` citation. ## Why this archive is dated 2026-10-24 and not 2026-10-09

All five plans of Phase 3 executed 2026-10-08/09, but the final gate stood **NOT PASSED** from
2026-10-09 because criterion 6, as then worded, demanded an exhaustive enumeration of future exception
branches — not finitely verifiable. The wording was restated as the finite, drift-checked inventory on
2026-10-23 (v1.2 GATE-01), the missing evidence was written (GATE-03), the gate re-ran clean
(GATE-04), and the UAT executed on the installed build (UAT-01/02). v1.0 ships with the gate verdict
**PASSED** recorded in `03-05-SUMMARY.md`, not on the strength of a green suite alone.
