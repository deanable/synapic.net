<objective>
Create the headless `Synapic.Core` library and move the inference transport, the sidecar host and the Serilog
facade into it, replacing the `Session` device coupling with an injected provider.

Purpose: the engine currently cannot run outside the Avalonia executable; every later indexer phase needs it to.
Output: a buildable `Synapic.Core`, `Synapic.Main` compiling against it, and a green build with unchanged behavior.
</objective>

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | executable path override | mitigate | The override is used verbatim only when it points to an existing file; no shell invocation, `ProcessStartInfo` with arguments list (existing pattern) |
| T-04-02 | Elevation | device string from config | mitigate | `NormalizeDevice` whitelist stays the only mapping; unknown values are CPU |
| T-04-01-SC | Tampering | NuGet adds | accept | Only Serilog packages already used by the app, pinned to the existing properties |
