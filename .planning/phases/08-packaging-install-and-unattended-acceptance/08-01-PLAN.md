<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| installer (elevated) → service | Elevated install creates a machine-wide service and event source |
| payload → Program Files | Files are taken over from a build directory |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Elevation | installer run entry | mitigate | Only the shipped exe with a fixed `--install` argument; no user-controlled parameters |
| T-08-02 | Tampering | payload | mitigate | Existing installer identity/signing flow unchanged; no new download step |
| T-08-03 | Denial of service | install order | mitigate | Service installed after payload and runtime; start failure is logged and does not abort the app install silently (report in the finish page/log) |
| T-08-01-SC | Tampering | NuGet adds | accept | No new packages |
</threat_model>
