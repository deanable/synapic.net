    `WorkIntake` wrapping the repository: one repository call, one Information log
    (`"enqueued {n} of {m} candidate(s), {s} skipped"`), Debug when both are zero. This is the only enqueue path in
    the service.

  <action>
    `LocalFolderScanSource : IWorkSource` takes the configured `IndexerConfig`, the repository, the hasher and the
    intake. `ScanAsync` walks `cfg.Schedule.WatchPaths` (a missing/blank root is a Warning plus one error count,
    never a throw), cancels between files, and for each `.jpg/.jpeg/.png/.tif/.tiff` file:
    canonicalize the key, de-duplicate across roots in a local `HashSet&lt;string&gt;(StringComparer.OrdinalIgnoreCase)`,
    skip `Length == 0` with a Debug log; load the existing row by key; if the row is Completed and its size and
    last-write UTC equal the file's (`File.GetLastWriteTimeUtc`), skip without hashing; otherwise compute the hash
    and build the `JobCandidate` with the size/mtime/hash. Collect candidates, hand them to `IWorkIntake` once at
    the end of the walk (one transaction, one log line), and return `SourceScanResult`. Catch
    `IOException`/`UnauthorizedAccessException`/`DirectoryNotFoundException` per file and per root, log a Warning
    naming the path, increment `Errors`, and continue. Never call `EnumerateFiles` without the CONTEXT's
    `EnumerationOptions` (reparse points, inaccessible subtrees).
  </action>
  <verify>dotnet build src/Synapic.Indexer --nologo -v minimal → 0/0; grep -n "AttributesToSkip\|ReparsePoint\|IgnoreInaccessible\|RecurseSubdirectories" src/Synapic.Indexer/Detection/LocalFolderScanSource.cs</verify>
  <acceptance_criteria>
