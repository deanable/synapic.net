  <action>
    `DaminionWorkSource : IWorkSource` is constructed only when `datasource.type == "daminion"`. Construction
    decrypts `encryptedPassword` through the indexer's `DpapiCredentialProtector`; a null/empty ciphertext or a
    decryption failure throws `IndexerConfigurationException` whose message names
    `datasource.daminion.encryptedPassword` and tells the operator to run `--set-daminion-password` (Program.cs
    already turns configuration exceptions into exit code 2 before any host is built).
    `ScanAsync` builds `new DatasourceSelection { IsDaminion = true, DaminionClient = client, Scope = cfg.Scope,
    UntaggedFields = cfg.UntaggedFields.ToArray(), StatusFilter = "all", MaxItems = 0 }` and calls
    `WorkflowRunner.FetchItemsAsync(ds, ct)`; per returned `ProcessWorkItem` it emits a `JobCandidate`
    (`key = "daminion|" + DaminionId`, `Source = "daminion"`, `DaminionId`, `FileName`,
    `Size = SizeBytes`, `MtimeUtc = null`, `ContentHash = ServerHashCode != 0 ? "srv:" + ServerHashCode : null`) and
    passes the batch to `IWorkIntake`. A missing `DaminionId` is a Warning and a skipped item, never a key of
    `"daminion|"`. On `DaminionNetworkException`/`DaminionAuthenticationException` it logs a Warning (message only,
    never the password) and returns `SourceScanResult { Unavailable = true }` with no candidates — the scheduler
    never sees the exception.
    Tests use a local `HttpMessageHandler` stub in the shape the existing Daminion tests use (no live server):
    (a) scope and untagged fields reach the client request; (b) items map to `daminion|<id>` keys with
    `srv:<hash>` fingerprints and zero-hash items keep a null hash; (c) a 500/connection failure yields
    `Unavailable` and enqueues nothing; (d) construction with a null or foreign password blob throws the message
    naming the config key.

    `ILogger`. It runs every source once immediately, then loops `Task.Delay(interval, clock, ct)`. Per run it logs
    `"scan: source=local found=… enqueued=… skipped=… errors=…"` at Information, a zero-everything run at Debug,
    an unavailable source at Warning, and it catches `OperationCanceledException` for shutdown and any other
    exception per source so one failing detector never ends the loop.
    `QueueSidecarActivity : ISidecarActivity` wraps the repository's `GetActivityAsync` behind a 1-second cache
