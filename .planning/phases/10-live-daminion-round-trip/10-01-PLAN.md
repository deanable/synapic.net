<objective>
Open the live path: one script that supplies the saved credential without exposing it, and one opt-in
test that proves the run knows which server, catalog, scope and counts it is working against.

Purpose: DAM-01, DAM-04.
</objective>

<tasks>

1. Write `build/acceptance-daminion.ps1`: resolve `SYNAPIC_TEST_DAMINION_*` first, else read
   `HKCU\Software\Synapic\Daminion` (ServerUrl/Username/PasswordEncrypted) and unprotect the blob with
   `ProtectedData` and the app's entropy. Set the three variables in the child process environment only,
   report which source was used and the server URL (never the password), and exit 3 with a stated reason
   when neither is available.
2. Add `tests/Synapic.Indexer.Tests/DaminionLiveAcceptanceTests.cs` — `[Trait("Category","Live")]`,
   `[SkippableFact]`, helpers that skip with the exact reason (no credentials, unreachable server).
3. DAM-01 test: authenticate, read the catalog GUID, resolve saved search 16's name through
   `GetSavedSearchesAsync`, count the scope and the untagged subset with `GetFilteredItemCountAsync`,
   and print one report block. Assert the counts are positive and consistent (untagged ≤ total).
4. Document the live tier in `docs/testing.md`: the script command, the credential sources, what it
   writes, and that a missing server/credential is a skip with a reason.

</tasks>
