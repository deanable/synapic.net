<objective>
Prove the outage row against a real unreachable server rather than a closed port.

Purpose: DAM-03. The block is a firewall rule on this machine, bounded and removed in a `finally`; the
test proves the block is real before asserting a pause, and proves it is gone before asserting completion.
</objective>

<tasks>

1. Add the resume log line to `BatchExecutor`: when a paused run's window has elapsed, log that the
   catalog is available again and the run resumes, naming how long it was paused. Pin it with a
   `ResilienceTests` fact using the fake clock (pause → advance → next batch logs the resume).
2. Write `build/block-daminion.ps1`: resolve the server's addresses, add an outbound TCP block rule for
   them, write `block.ack`, wait for `unblock.request` (bounded), remove the rule and write `unblock.ack`.
   The rule name is fixed (`Synapic live outage`) and the removal runs in `finally`.
3. Live test: enqueue 6 items from the scope; the sidecar hook requests the block after the first item's
   tag and waits for `block.ack` plus a failed authentication from a fresh client. Assert the pause
   (`IsPaused`, no Failed, no InFlight, pending rows intact). Request the unblock, wait for a fresh client
   to authenticate, advance the harness clock past the pause window, run batches until every row is
   `Completed` (bounded), and assert the log named the pause and the resume.
4. Record in the transcript that a block during the *write* yields a transient retry (write returns false)
   while a block during the *download* yields the pause — both keep the row.

</tasks>
