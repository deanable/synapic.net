<objective>
Run the package the way an administrator would and record what happened.

Purpose: MSI-02, MSI-03, MSI-04. This is the phase's real gate: a package that builds and validates still has
to install, launch the current app, register a service, upgrade over itself and come back off cleanly.
</objective>

<tasks>

1. Elevated: silent install, then a second install over the first, capturing ARP entries, service
   configuration, installed file count, stray installer/pdb count and the installed host DLL hash.
2. Non-elevated: launch the installed `Synapic.exe`, walk its UI Automation tree for the dashboard and the
   four panels, close it, and kill any sidecar it started.
3. Elevated: uninstall and verify 1060, absent Program Files, intact ProgramData and unchanged queue hash.

</tasks>

<verification>

- The three transcripts record exit code 0 for every msiexec call and the expected state at each step.
- The dashboard check finds the dashboard and the Settings, Tagging, Deduplication and Upscaling panels.
- No `Synapic-Setup-*.exe` and no `.pdb` under `C:\Program Files\Synapic`.

</verification>
