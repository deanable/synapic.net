<objective>
Make the two installers describe the same payload, and make disagreement fail the build instead of shipping.

Purpose: MSI-01/MSI-05. The MSI was missing the exclusion for the Inno output that sits in its own payload
folder, so a build after a release would have installed a 302 MB copy of the other installer into Program Files.
</objective>

<tasks>

1. Add `<Exclude Files="$(var.PayloadDir)\Synapic-Setup-*.exe" />` to the MSI's `ApplicationFiles` group and
   document why it exists.
2. Write `build/check-installer-payloads.py`: compare the payload root each manifest globs, the exclusion
   patterns as sets, and that both packaging scripts name `Synapic.Indexer.exe`, `Synapic.Core.dll` and
   `synapic-inference.exe`. Exit 1 with the differing pattern named.
3. Run the guard from both `package-windows.ps1` and `package-windows-msi.ps1` before compilation.
4. Delete the stale `artifacts/win-x64/smoke.log` so neither installer carries it.

</tasks>

<verification>

- `python build/check-installer-payloads.py` exits 0 on the repository.
- Removing the new exclusion from a copy of the .wxs makes it exit 1 naming `synapic-setup-*.exe`.
- Removing `Synapic.Core.dll` from a copy of `package-windows.ps1` makes it exit 1 naming the file.

</verification>
