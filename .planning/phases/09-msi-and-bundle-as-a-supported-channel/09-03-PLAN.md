<objective>
Prove what the package carries, at the only point where it can be checked cheaply: right after it is built.

Purpose: MSI-01. The payload checks prove the folder is complete; only the File table proves the glob selected it.
</objective>

<tasks>

1. Add `Get-MsiFileNames` (Windows Installer COM, read-only) and call it after `wix build`.
2. Fail by name on a missing required file, on a forbidden file, and on a PDB.
3. Compare the whole package against the payload folder minus exclusions and report the first ten differences.
4. Build once with a fresh publish and once with `-SkipPublish`, and record the artifact sizes.

</tasks>

<verification>

- `pwsh build/package-windows-msi.ps1 -SkipPublish` exits 0 and prints the verified file count.
- `wix msi validate artifacts/msi/Synapic-win-x64.msi` reports only the documented ICE61.
- The MSI is materially smaller than the Oct-14 build (543 MB) now that the Inno output is excluded.

</verification>
