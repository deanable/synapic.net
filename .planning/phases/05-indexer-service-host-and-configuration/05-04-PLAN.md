  <action>
    `ServiceInstaller` runs `sc.exe` via `ProcessStartInfo { UseShellExecute = false, RedirectStandardOutput = true }`
    with ArgumentList; `InstallAsync` queries first (idempotent), creates the service, sets recovery, creates the
    Event Log source if missing (`EventLog.CreateEventSource("SynapicIndexer", "Application")`), and calls
    `ProgramDataSetup.Ensure(paths)`; `UninstallAsync` runs `sc stop` (ignore 1062 not-running), waits up to 10 s
    for `sc query` to report STOPPED, then `sc delete`; logs each exit code. `ProgramDataSetup.Ensure` creates
    `%ProgramData%\Synapic`, `Logs`, `state` and grants modify to `NT AUTHORITY\SYSTEM` and
    `NT AUTHORITY\LocalService` using `icacls` with an argument list (`/grant *S-1-5-18:(OI)(CI)M`,
    `*S-1-5-19:(OI)(CI)M`) — SIDs, not localized account names. `PasswordCommand.Run` reads the password without
    echo (`Console.ReadKey(intercept: true)`), protects with LocalMachine DPAPI, saves via the store, prints only
    "saved". All commands return non-zero on failure with the sc.exe/icacls output logged.
    Wire the modes in `Program.Main` before host construction; Console mode continues into the host.
  </action>
