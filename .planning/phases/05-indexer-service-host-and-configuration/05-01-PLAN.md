<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| registry/JSON → process | Configuration is administrator-authored input; a malicious or broken value must not become a command |
| DPAPI ← credential | The encrypted password is at rest in a ProgramData file |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Information disclosure | `indexer-config.json` | mitigate | Only the DPAPI-LocalMachine ciphertext is stored; logs never receive it; ACLs in 05-04 restrict the folder |
| T-05-02 | Elevation | `device`/paths from config | mitigate | Device whitelist; watch paths must be absolute and existing; no shell, no command strings built from config |
| T-05-03 | Tampering | malformed JSON | mitigate | Parse failure becomes a validation error; `SaveDaminionPassword` preserves unknown members |
| T-05-01-SC | Tampering | NuGet adds | accept | Microsoft.Extensions.* 10.0.12 aligns with the app's existing packages; EventLog is in-box for Windows |
</threat_model>
